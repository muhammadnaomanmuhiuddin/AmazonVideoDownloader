Amazon Media Downloader (Chrome, Manifest V3)

Install:
1. Unzip this folder.
2. Open chrome://extensions and turn on Developer mode.
3. Click "Load unpacked" and select the folder.
4. Open an Amazon product page, click the extension icon.

If a video isn't listed: reload the page, press play on the video, reopen the popup.
Only unencrypted listing videos are supported (no Prime Video / DRM content).
